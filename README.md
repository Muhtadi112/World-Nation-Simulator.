# World Nation Simulator

An offline-first Android nation and city simulation built with Godot 4.

> Current milestone: Phase 1 playable foundation. This repository is the project foundation, not a finished game or APK yet.

## Project status

- Landscape mobile layout
- Career and Sandbox entry points
- Country selection and world dashboard foundation
- Local save/load and simulation clock foundation
- Godot 4 / GDScript

## Run

Open this folder in Godot 4.3 or newer and run `project.godot`.

## Build status

GitHub Actions validates the project in headless Godot. Android APK export will be added after the Android export toolchain and signing configuration are set up.
